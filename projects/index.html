WebConlangPCG

Solo · Live tool

Voices of Void

Proto-language workbench — presets, phonology, writing systems, dictionary, and live translation.

Play Repo

About

A dark sci-fi conlang generator for rapid worldbuilding ideation. Load a preset, tweak grammar and phoneme inventories, then generate sample sentences and a mini-dictionary.

Technical

Vanilla JS UI + rule-based word/sentence generation, syllable patterns, writing-system options, and custom word mapping. No build step — runs as a static web app.

p5.jsGenerativeImages

Solo · Live tool

Circle Image Generator

Pick an inspiration image and watch colored dots mutate into the picture over time.

Play Repo

About

An evolutionary / pointillist recreation toy. Start from a target photo, seed translucent circles sampled from image colors, then mutate and grow the cloud until the subject emerges.

Technical

p5.js canvas with tunable mutation rate, circle counts, radius, and alpha. Score tracks pixel error vs the inspiration image. Drop more images into the assets folder and register them in getInspirations().
