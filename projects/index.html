WebConlangPCG

Solo · Live tool

Voices of Void

Proto-language workbench: presets, phonology, writing systems, dictionary, and live translation.

Repo

About

A dark sci-fi conlang generator for rapid worldbuilding ideation. Load a preset, tweak grammar and phoneme inventories, then generate sample sentences and a mini-dictionary.

Technical

Vanilla JS UI + rule-based word/sentence generation, syllable patterns, writing-system options, and custom word mapping. No build step, runs as a static web app.

Available in Live Toys → Language Generator.

2048 Boss Battle

A roguelike twist on 2048: merge tiles to power up and defeat boss enemies. Designed with mobile touch controls in mind.

Repo

About

Modified the classic 2048 mechanic into a boss battle roguelike. Each tile merge translates into combat actions against progressively harder bosses. Planned for mobile release with touch controls.

Technical

Pure web (HTML/CSS/JS). Boss logic layers on top of standard 2048 grid mechanics. Touch-gesture support planned for mobile port.
