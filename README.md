# Efe Ayan Portfolio

Minimal neon portfolio inspired by a clean Home → Technologies → Featured Projects structure.

## Pages

| Path | Description |
|------|-------------|
| `/` | Home - portrait, title, tech logos, featured projects |
| `/about/` | About Me |
| `/projects/` | Polished / team game projects |
| `/minis/` | Prototypes, shaders, TouchDesigner, audio sketches |
| `/toys/` | Live Toys - embeds **Voices of Void** conlang generator |
| `/contact/` | Contact form |

## Live Toys

The language generator is vendored from [VoicesOfVoid](https://github.com/UtkuEfeAyan/VoicesOfVoid) into `toys/voices-of-void/`.

## Run locally

Node.js 24+:

```bash
npm start
npm run check
```

## GitHub Pages

Deploys from `main` via `.github/workflows/deploy-pages.yml`.
